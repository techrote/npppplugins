# npppplugins

Notepad++ plugin collection.

## Plugins

| Plugin | Purpose | Status |
| --- | --- | --- |
| [TokenStatus](plugins/TokenStatus/README.md) | Adds a rough token count alongside length and lines in the bottom status bar | Initial Windows x64 implementation; live Notepad++ smoke test pending |

TokenStatus source, tests, installation notes and Windows build instructions are in [plugins/TokenStatus](plugins/TokenStatus/README.md). GitHub Actions compiles the Windows DLL and publishes it as a downloadable workflow artifact.

This repository is not affiliated with the Notepad++ project.
